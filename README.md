# 🎓 קורס הבנת כלי ה-AI - LMS

מערכת למידה אינטראקטיבית (LMS) מקצה לקצה לניהול קורס הבנת כלי בינה מלאכותית, פרומפטינג והנדסת אנוש מולם. המערכת מאפשרת לסטודנטים ללמוד את סילבוס הקורס, לתרגל מבחנים אמריקאיים ולקבל ציון ומשוב אוטומטי מיידי.

🚀 **האתר באוויר באקליק:** [כניסה למערכת ה-LMS שלך](https://prompt-academy-lms.onrender.com)

---

## 🛠️ טכנולוגיות וארכיטקטורה

המערכת בנויה בארכיטקטורת Full-Stack מודרנית וקלילה:
* **Frontend (ממשק משתמש):** HTML5, JavaScript (Async/Fetch API) ועיצוב רספונסיבי בעזרת **Tailwind CSS**.
* **Backend (שרת):** **Node.js** יחד עם פרימוורק **Express** לניהול נתיבים (API Routes) וטיפול ב-CORS.
* **Database (מסד נתונים קבוע):** אינטגרציה מלאה עם **Google Sheets** דרך ה-API של SheetDB לשמירה קבועה של ציוני הסטודנטים בזמן אמת.
* **Cloud Hosting (אירוח בענן):** השרת והאתר מאורחים ומנוהלים על פלטפורמת **Render** (שרת אירופאי בפרנקפורט לביצועים מהירים).

## 📝 מבחני ההסמכה

* לכל מודול 4 שאלות אמריקאיות עם 4 אפשרויות, וציון מעבר של 75.
* מאגר השאלות, התשובות וההסברים נמצא בקובץ `quiz.js` בצד השרת בלבד. הדפדפן מקבל את השאלות **בלי** התשובות (`GET /api/modules/:num/quiz`), והבדיקה נעשית בשרת (`POST /api/submissions`).
* סדר האפשרויות מעורבב בכל טעינה, ואחרי ההגשה מוצג לכל שאלה הסבר קצר.
* ההתקדמות האישית (אילו מודולים עברו והציון הגבוה ביותר) נשמרת ב-`localStorage` של הדפדפן בלבד.

## 📊 מבנה מסד הנתונים (Google Sheets)

אם הוגדר `SHEETDB_URL`, כל הגשה נרשמת בגיליון עם העמודות הבאות:
1. `id` - מזהה ייחודי להגשה (Timestamp).
2. `שם` - שם הסטודנט כפי שהוזן.
3. `מספר מודל` - מספר המודול.
4. `שאלה` - כמה תשובות נכונות מתוך כמה (למשל `3/4 נכונות`).
5. `תשובה` - התשובות שנבחרו (JSON).
6. `feedback` - ✅/❌ לכל שאלה.
7. `ציון` - הציון הסופי (0-100), מחושב בשרת.

## 💻 הרצה מקומית על המחשב (Local Development)

1. ודאו שמותקן [Node.js](https://nodejs.org/) בגרסה 18 ומעלה.
2. התקינו את הספריות:
   ```bash
   npm install
   ```
3. העתיקו את `.env.example` ל-`.env` ומלאו את הערכים (`SHEETDB_URL` אופציונלי - בלעדיו הציונים נבדקים אך לא נשמרים בגיליון).
4. הפעילו את השרת:
   ```bash
   npm start
   ```
   והיכנסו ל-`http://localhost:5000`.
5. הרצת הבדיקות האוטומטיות:
   ```bash
   npm test
   ```

### ⚙️ משתני סביבה

| משתנה | חובה? | תיאור |
| :--- | :---: | :--- |
| `PORT` | לא | פורט השרת (ברירת מחדל 5000). |
| `SHEETDB_URL` | לא | כתובת ה-API של SheetDB לשמירת ציונים. **לעולם לא לשמור בקוד** - רק במשתני הסביבה של Render / בקובץ `.env`. |
| `ALLOWED_ORIGIN` | לא | דומיין חיצוני שמורשה לקרוא ל-API. ריק = רק האתר עצמו. |
